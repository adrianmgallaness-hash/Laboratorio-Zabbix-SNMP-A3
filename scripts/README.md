# Comandos de configuración

- [R1](R1.cli) configura la interfaz LAN, el pool DHCP, la ACL 31 y SNMP de solo lectura.
- [Switch](SW1.cli) configura el enlace con R1, la dirección de gestión en Vlan1, la ACL 31 y SNMP de solo lectura.

Los marcadores de comunidad se sustituyeron antes de aplicar los comandos en el laboratorio. Los running-configs de los equipos están en [configs](../configs/README.md).
